# Weekly System — backlog

Задачи подготовлены так, чтобы их можно было переносить в GitHub Issues без изменения смысла.

Обозначения приоритетов:

- `P0` — необходимо для рабочего вертикального среза MVP;
- `P1` — необходимо до выпуска MVP;
- `P2` — допустимо после первой рабочей версии.

## Epic 2 — single-user authentication и доступ

- [ ] **WS-201 · P0 · Реализовать вход единственного пользователя**

  - Хранить только Argon2id-хэш пароля.
  - Реализовать `/login`, logout и возврат на ранее запрошенный маршрут.
  - Добавить серверные сессии с непрозрачным токеном и хранением только token hash.
  - Выдавать cookie с `HttpOnly`, `Secure`, `SameSite=Strict` и сроком 30 дней.

## Definition of Done для каждой задачи

- Реализация соответствует связанным требованиям.
- Добавлены тесты пропорционально риску изменения.
- Lint, typecheck, tests и production build проходят.
- Обработаны loading, empty и error states для пользовательского UI.
- Не добавлены секреты или чувствительные данные в код, логи и fixtures.
- Документация обновлена, если изменился публичный контракт или пользовательский сценарий.
